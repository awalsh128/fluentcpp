Fluent C++

Statically typed, fluent query functions for C++20 containers that are easy to discover through auto-complete.

Remarks
If you find this project useful, please consider supporting it as a sponsor and show some ❤️ for open source maintainers.

Wrap a container in fcpp::query and chain operations on it, instead of writing loops and temporary containers by hand.

fcpp::query(xs)
.where(EXPR(x, x > 500))
.select(EXPR(x, x % 10))
.distinct()
.to_vector();

  • :link: Chain filtering, projection, ordering, set and grouping operations in a single expression.
  • :mag: Find every operation through auto-complete on the returned fcpp::Queryable<T>.
  • :zap: Write terse lambdas with the EXPR and CR_EXPR macros.
  • :package: Works with move-only types; items are moved through the chain rather than copied.

Installation

Install the latest release with a single command:

curl -fsSL https://raw.githubusercontent.com/awalsh128/fluentcpp/master/scripts/install.sh | bash

This downloads the source, builds the library and installs it to /usr/local/lib/fluentcpp, with the headers in /usr/local/include/fluentcpp. It runs as your user and only asks for sudo to copy the files if the install location isn't writable. Requires curl, CMake 3.16.3 or newer, and a C++20 compiler; clang++ and Ninja are used when available.

Pass options after bash -s -- to pick a version or install location:

curl -fsSL https://raw.githubusercontent.com/awalsh128/fluentcpp/master/scripts/install.sh |
bash -s -- --version v0.2 --prefix "$HOME/.local"
Option Default Description
--version Latest release Release tag or branch to install, such as v0.2 or master.
--prefix /usr/local Installation prefix for the lib and include directories.

To build with a specific compiler, set CXX on the bash side of the pipe, for example ... | CXX=g++ bash. To read the script before running it, download it with curl -fsSLO and run bash install.sh.

Alternatively, download fluentcpp-<tag>.tar.gz from a release, extract it and run ./install.sh from the extracted directory.

Usage

Include the query header and wrap any std::vector:

#include <fluentcpp/query.h>
#include <iostream>
#include <vector>
int main() {
std::vector<int> xs;
for (int x = 0; x < 1000; x++) xs.push_back(x);
std::vector<int> result =
fcpp::query(xs)
.where(EXPR(x, x > 500))
.shuffle()
.skip(10)
.select(EXPR(x, x % 10))
.distinct()
.order_by(EXPR(x, x))
.branch(EXPR(x, x > 5))
.when_true([](auto q) { return q.select(EXPR(x, x + 100)); })
.when_false([](auto q) { return q.select(EXPR(x, x - 100)); })
.merge()
.select(EXPR(x, std::get<0>(x)))
.to_vector();
for (int x : result) std::cout << x << " ";
}

Building

Building from source requires Clang (clang++), CMake and Ninja:

sudo apt-get install -y clang cmake ninja-build

Debug Build with Tests

The debug preset in CMakePresets.json configures clang++, Ninja, tests and examples into build/debug:

cmake --preset debug
cmake --build --preset debug
ctest --preset debug

Or, without presets:

cmake -B build -G Ninja \
-DCMAKE_BUILD_TYPE=Debug \
-DCMAKE_EXPORT_COMPILE_COMMANDS=ON \
-DCMAKE_CXX_COMPILER=clang++ \
-DBUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure

Release Build and Install

cmake --preset release
cmake --build --preset release --target fluentcpp
sudo cmake --install build/release

Dependencies

  • CMake - Build system.
  • Clang - C++20 compiler used for builds, formatting and static analysis.
  • Catch2 - Unit test framework, fetched by CMake when BUILD_TESTS=ON.
  • Google Benchmark - Benchmark framework, fetched by CMake when BUILD_BENCHMARKS=ON.
  • Doxygen - API documentation generator, used when BUILD_WEBSITE=ON.
