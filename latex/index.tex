\doxysection*{Fluent C++}



Statically typed, fluent query functions for C++20 containers that are easy to discover through auto-\/complete. 



\href{https://github.com/awalsh128/fluentcpp/actions/workflows/ci.yml}{\texttt{}} \href{https://github.com/awalsh128/fluentcpp/blob/master/LICENSE}{\texttt{}} \href{https://en.cppreference.com/w/cpp/20}{\texttt{}} \href{https://cmake.org/}{\texttt{}} \href{https://github.com/awalsh128/fluentcpp}{\texttt{}}

\begin{DoxyItemize}
\item \+:link\+: Chain filtering, projection, ordering, set and grouping operations in a single expression.
\item \+:mag\+: Find every operation through auto-\/complete on the returned {\ttfamily \doxylink{classfcpp_1_1Queryable}{fcpp\+::\+Queryable}\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}}.
\item \+:zap\+: Write terse lambdas with the {\ttfamily \doxylink{query_8h_a4af4019a96b4243ad506824e53321028}{EXPR}} and {\ttfamily \doxylink{query_8h_a3eff0f74c45c60dc7a5edb32bb7cbf4a}{CR\+\_\+\+EXPR}} macros.
\item \+:package\+: Works with move-\/only types; items are moved through the chain rather than copied.
\end{DoxyItemize}

\hypertarget{index_autotoc_md1}{}\doxysubsection{\texorpdfstring{Installation}{Installation}}\label{index_autotoc_md1}
Install the latest release with a single command\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{curl\ -\/fsSL\ https://raw.githubusercontent.com/awalsh128/fluentcpp/master/scripts/install.sh\ |\ bash}

\end{DoxyCode}


This downloads the source, builds the library and installs it to {\ttfamily /usr/local/lib/fluentcpp}, with the headers in {\ttfamily /usr/local/include/fluentcpp}. It runs as your user and only asks for {\ttfamily sudo} to copy the files if the install location isn\textquotesingle{}t writable. Requires {\ttfamily curl}, CMake 3.\+16.\+3 or newer, and a C++20 compiler; {\ttfamily clang++} and Ninja are used when available.

Pass options after {\ttfamily bash -\/s -\/-\/} to pick a version or install location\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{curl\ -\/fsSL\ https://raw.githubusercontent.com/awalsh128/fluentcpp/master/scripts/install.sh\ |}
\DoxyCodeLine{\ \ bash\ -\/s\ -\/-\/\ -\/-\/version\ v0.2\ -\/-\/prefix\ "{}\$HOME/.local"{}}

\end{DoxyCode}



\begin{DoxyTable}{3}{}{}{1}

To build with a specific compiler, set {\ttfamily CXX} on the {\ttfamily bash} side of the pipe, for example {\ttfamily ... \texorpdfstring{$\vert$}{|} CXX=g++ bash}. To read the script before running it, download it with {\ttfamily curl -\/fs\+SLO} and run {\ttfamily bash install.\+sh}.

Alternatively, download {\ttfamily fluentcpp-\/\texorpdfstring{$<$}{<}tag\texorpdfstring{$>$}{>}.tar.\+gz} from a \href{https://github.com/awalsh128/fluentcpp/releases}{\texttt{release}}, extract it and run {\ttfamily ./install.sh} from the extracted directory.\hypertarget{index_autotoc_md2}{}\doxysubsection{\texorpdfstring{Usage}{Usage}}\label{index_autotoc_md2}
